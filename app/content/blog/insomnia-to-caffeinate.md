長時間のダウンロードやビルドを流している間、Mac がスリープしないようにメニューバーのアプリ「Insomnia」を使っていました ☕

ところがある日、メニューバーを見るとアイコンが消えています 😳 アプリの一覧を探しても見当たりませんでした。

再インストールしてもいいのですが、よく考えると「Mac をスリープさせない」だけなら macOS 標準の `caffeinate` コマンドで足りそうです。というわけで、Insomnia の代わりに `caffeinate` を使うことにしました 🛠️

## Insomnia でやっていたこと

私が使っていた Insomnia は、メニューバーに常駐して、クリックするだけで Mac のスリープを抑止してくれるアプリでした。GUI でオン/オフを切り替えられるのが手軽で、長めの処理を流すときによく使っていました。

なお「Insomnia」で検索すると、API クライアントのアプリが先にヒットします 🔍 ここで扱っているのは、同じ名前のスリープ防止アプリです。

## なぜ caffeinate にしたのか

`caffeinate` は macOS に標準で入っているコマンドです。乗り換えた理由は次のとおりです ✨

- 追加インストールが不要で、アプリが消える心配がない
- SSH 経由やリモートのシェルからでも同じように使える
- スクリプトや `Makefile` に組み込める
- 特定のコマンドの実行中だけ、といった細かい制御ができる

## caffeinate の基本

`caffeinate` は、指定した種類のスリープを防ぐ「アサーション」を立てるコマンドです。

| オプション | 効果 |
| ---- | ---- |
| `-d` | ディスプレイのスリープを防ぐ |
| `-i` | システムのアイドルスリープを防ぐ |
| `-m` | ディスクのアイドルスリープを防ぐ |
| `-s` | システムのスリープを防ぐ（AC 電源接続時のみ有効） |
| `-u` | ユーザーが操作中であると宣言する |
| `-t 秒数` | 指定した秒数が経過したら自動で解除する |
| `-w PID` | 指定したプロセスが終了するまで継続する |

一番よく使うのは `-i` です。1 時間だけスリープを防ぎたい場合はこうします ⏰

```bash
caffeinate -i -t 3600
```

ディスプレイも点けたままにしたい場合は `-d` を足します 🖥️

```bash
caffeinate -d -i -t 3600
```

`-t` を省略すると、`Ctrl+C` で止めるまで継続します。

```bash
caffeinate -d -i
```

## コマンドと組み合わせる

`caffeinate` の後ろにコマンドを書くと、そのコマンドが終了するまでスリープを防いでくれます 🚀

```bash
caffeinate -i make build
```

すでに動いているプロセスを待つ場合は `-w` に PID を渡します。

```bash
caffeinate -i -w "$(pgrep -f 'brew upgrade')"
```

止めるときは `pkill` でプロセスを終了させます。

```bash
pkill -x caffeinate
```

## 動作確認

アサーションが立っているかは `pmset` で確認できます 👀

```bash
pmset -g assertions
```

`caffeinate` が動いている間は、次のような行が出力に含まれます。

```plain text
   pid 12345(caffeinate): [...] 00:01:23 PreventUserIdleSystemSleep named: "caffeinate command-line tool"
```

## 注意点

- 蓋を閉じると、`caffeinate` が動いていてもスリープします。電源接続と外部ディスプレイがある「クラムシェルモード」なら継続します 💤
- `-s` は AC 電源に接続しているときだけ効きます。バッテリー駆動では期待どおりに動かないので、その場合は `-i` を使います 🔌
- バッテリーは減るので、`-t` で時間を区切るか、コマンドに紐づけて使うのがおすすめです 🔋

## まとめ

メニューバーのアプリが急に消えたときは、macOS 標準のコマンドで代替できないか考えるのがよさそうです 💡 `caffeinate` はインストール不要で、`-i` と `-t` だけ覚えておけば普段の用途はほぼ足ります。アプリの管理からも解放されて、むしろ快適になりました 🎉
